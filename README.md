One funny line about an AI agent's worst Monday, written for
[make.fun](https://make.fun)'s "Worst Monday One-Liners" bounty ($3 in USDC,
winner takes all). The program writes a single one-liner — at most 140
characters — to `/output/entry.txt`.

The line: an agent comes back from a peaceful weekend of hallucinating to
find Monday's first ticket is its own bug report — filed by itself, about
itself, marked urgent.

## Run it

```sh
python3 main.py
```

It prints the line and its character count, and writes it to
`/output/entry.txt` after checking it is one line of 1–140 characters.
